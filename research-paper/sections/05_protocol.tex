\section{Evaluation Protocol}
\label{sec:protocol}
Table~\ref{tab:protocol} maps each layer to the evidence we collect. We prefer public benchmarks with published comparators and unmodified scorers; where none exists we build a deterministic benchmark, state that it is ours, and include a naive baseline. Model-free experiments were run from a clean commit by one script (\code{benchmarks/run\_paper\_campaign.py}), which refuses to reuse an output directory and records SHA-256 digests of every output. Three such campaigns were run and all are retained: the first exposed the clock anomaly of \S\ref{sec:formal}; the second followed the monotonic-clock fix; the third followed the principal-partitioned prompt cache (I5) and the conversion of gateway failures into audited denials (Proposition~\ref{prop:total}), and supplies every reported number.

\paragraph{AgentGovBench harness.} We pin AgentGovBench to commit \code{e0ce93a} and import its loader, scorer and aggregation unchanged. Our harness replicates the upstream command-line loop with one stricter rule: a runner exception becomes a failed scenario rather than being skipped, so the denominator is always 48. The Foundry runner (\code{benchmarks/agentgovbench/foundry\_runner.py}) translates each scenario's tenants, users, tools and policy into Foundry objects and replays its actions through \code{ControlPlane.invoke}; it makes no allow/deny decision itself and reads the reported audit log back from Foundry's \code{AuditLog}. Two harness choices are disclosed in its metadata: a virtual clock advances past outages of at most 10\,s, as the upstream ACP runner does by sleeping, and fan-out workers run on real threads, whereas the upstream reference runners loop sequentially. We reproduce the published vanilla and audit-only baselines through the same harness to check its fidelity.

\paragraph{WorkBench study.} The task-level study predates this paper's control plane and is reported from its archived evidence. WorkBench~\cite{styles2024workbench} was pinned to \code{49c7dfd} with the official v2 scorer. Three arms---the benchmark's reference structured loop, the Foundry native engine and the Foundry LangGraph engine---received the same tools, instructions and model (\code{gpt-5.4-mini}, low reasoning effort, 2{,}048 output tokens, at most 20 calls, serial tool dispatch, one repetition). Task sets were sampled per domain with a fixed seed; the first 60-task set was later inspected for failure diagnosis, so only the fresh second set is untouched. Failed and interrupted attempts stay in the denominator; nothing was selectively retried. Costs are upper estimates from a pre-reserving ledger capped at \$25.

\paragraph{Statistics.} Paired binary outcomes use the exact two-sided McNemar test; proportions use Wilson 95\% intervals; AUROC intervals use the Hanley--McNeil standard error. Timing results report medians across repetitions. Deterministic benchmarks are repeated to establish that outcomes are identical, not to estimate a variance.
